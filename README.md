## 🌌 Overview
*Artemis Mission Shield* is an interactive, real-time Lunar Outpost Mission Control & Cybersecurity Monitoring dashboard built with *Python, Streamlit, Pandas, and NASA's Near-Earth Object (NEO) API. Designed as a hands-on Junior Astronaut Mission Trainer, it challenges operators to balance critical lunar life-support resources (Oxygen, Power, Food Supply, Radiation, and Communication Integrity*) while monitoring live space threats and defending outpost systems against cyber anomalies.

## ✨ Key Features
- *Live NASA Deep-Space Threat Feed:* Connects to NASA's NeoWs REST API to track real-time Near-Earth Objects and approach velocities.
- *Interactive Mission Simulator:* Dynamic resource and environmental sliders that calculate a real-time *Mission Performance Score (0–100)* and trigger instant life-support alerts.
- *Cybersecurity Monitoring Center:* Built-in system integrity diagnostics, threat alerts, and an automated *Cybersecurity Event Log* with one-click CSV audit export.
- *Mission History Snapshots:* Captures timestamped telemetry checkpoints exportable as .csv mission reports.
- *Deep-Space Dark UI:* Custom CSS starfield interface built for immersive mission control training.
